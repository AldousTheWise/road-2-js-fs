API de Gestión de Tareas

Servidor HTTP creado con Node.js puro

    Endpoints Disponibles:

    GET /api/tareas

    Listar todas las tareas. Parámetros opcionales: completada, prioridad, q

    GET /api/tareas/:id

    Obtener tarea específica por ID.

    POST/api/tareas

    Crear nueva tarea:

                {
                "titulo": "Mi nueva tarea",
                "descripcion": "Descripcion opcional",
                "prioridad": " alta | media | baja "
            }
    PUT /api/tareas/:id

    Actualizar tarea existente.

    DELETE /api/tareas/:id

    Eliminar tarea

    Ejemplos de Uso.

    Listar tareas:

    curl http://localhost:3000/api/tareas

    Crear tarea:

            curl -X POST -H "Content-Type: application/json"\
        -d '{"titulo" : "Aprender HTTP", "descripcion":"Estudiar protocolos web"}' \
        http://localhost:3000/api/tareas

    Buscar tareas:

    curl "http://localhost:3000/api/tareas?q=aprender"

    Filtrar por estado:

    curl "http://localhost:3000/api/tareas?completada=false"
